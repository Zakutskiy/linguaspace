# LinguaSpace 5.0

Сайт центра изучения иностранных языков: https://linguaspace.infinityfree.me/

## Состав
- `wp-content/themes/linguaspace` — собственная тема версии 5.0.
- `wp-content/plugins/linguaspace-content-import` — плагин импорта 25 страниц и 15 записей в трех рубриках.
- `seo` — 60 запросов и результаты аудита автономной версии 4.0; частотность и конкурентность еще не измерены.

## Развертывание
1. Установить WordPress на сервере с PHP и MySQL/MariaDB.
2. Скопировать папки темы и плагина в соответствующие каталоги wp-content или упаковать каждую в отдельный ZIP для загрузки через панель WordPress.
3. Активировать тему LinguaSpace и плагин LinguaSpace Content Import.
4. Открыть «Инструменты → Импорт LinguaSpace» и запустить импорт. Повторный импорт заменяет содержимое импортированных страниц.
5. Установить WP Mail SMTP из каталога WordPress, выбрать Gmail и настроить собственный OAuth-клиент, включив Gmail API. URI перенаправления: https://connect.wpmailsmtp.com/google/. Секретные ключи хранятся только в настройках CMS.
6. Проверить адрес администратора WordPress: на него отправляются заявки через wp_mail(). Проверить поиск, переходы и получение тестового письма.
